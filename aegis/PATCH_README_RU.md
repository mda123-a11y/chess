# AEGIS v17 — три карты на едином ядре

Распакуйте в отдельную папку. Старый частичный UI-патч накладывать не нужно: это полный каталог игры.

## Запуск на ПК
Самый надёжный вариант — локальный HTTP-сервер. Откройте терминал в папке с index.html:

```
python -m http.server 8765
```

Затем откройте http://localhost:8765/ в актуальном Chrome/Edge/Firefox с WebGL2. Нужен Python 3; на некоторых системах команда называется python3. Файлы игры обслуживаются локально; внешняя библиотека карт не загружается.

## Использование
1. В оружейной полигона выберите генерала, оружие, патроны и гранаты.
2. Вселитесь в генерала. Esc → «В бой» → нужная карта.
3. Доступны Заречье, Тихий бор и Ангар. Во всех работает AEGIS, а не автономная FPS-игра карты.
4. Esc → «В бой» → «Учебный полигон» — вернуться с текущим снаряжением и остатками боезапаса.

## Что изменено
- Фон загрузки из второго скриншота.
- «В бой» в паузе и увеличенное окно на три карточки без ANGAR-07.
- Три реальных окружения с адаптерами коллизий и безопасным появлением.
- Четыре генерала и восемь дополнительных бойцов на карту.
- Старые руки, оружие, HUD, дрон и управляемый артудар автономных карт не запускаются.
- Слоты, обвесы, магазины/патронник, резерв и использованные гранаты переносятся между локациями.

## Ограничения
Это тестовая интеграция, не финальная оптимизированная версия для слабых ПК. На реальном слабом железе она не проверялась. Гарантии отсутствия лагов нет. Количество бойцов не равно 40/80 со старых карточек. Смена локации перезагружает страницу; ранения, позиции и разрушения предыдущей карты не сохраняются. Старые системы разрушения, ткань и динамическая физика автономных карт не перенесены. Пиксельное совпадение освещения со старыми страницами не обещается. Для применения плотности растительности после изменения качества заново войдите на карту.

Детальные мини-планы, ссылки и границы реализации: docs/CHANGE_PLAN_RU.md. Свежие результаты: tools/map-tests/REPORT_RU.md. Старые отчёты, унаследованные от исходной игры, не считаются подтверждением этой интеграции.
