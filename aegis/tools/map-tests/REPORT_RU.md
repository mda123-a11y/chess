# Проверки интеграции трёх карт

Среда: Linux, headless Chromium, программный WebGL/SwiftShader. Это не реальные слабые ПК и не игровой FPS-бенчмарк.

## Пройдено
- Синтаксис новых модулей карт и адаптера: node --check.
- Изолированный DOM/CSS/UI: 1920×1080, 1366×768, 1280×720, 1024×768; CPU slowdown ×1/×4/×6/×4. Три активные карточки в ряд, внутри панели, пауза и возврат без изменения инвентаря. tools/ui-tests/results.json. API игры на этом стенде подменён.
- Сквозной запуск: Заречье → Ангар → Тихий бор → полигон, настоящая игра. По 120 шагов × 1/30 с на каждой боевой карте. 12 персонажей на боевой карте, четыре на полигоне. Все позиции конечны; в исходных спавнах нет пересечений со статическими коллизиями.
- Перенос выбранного генерала alpha_1 с MP5A3, Glock18C, обоими боеприпасными слотами и гранатами M67/M84. После установки тестового состояния сохраняются 3 патрона в оружии, 7 в резерве и использованная граната слота 4, включая обратный вход на полигон. Экипировка остальных генералов остаётся пустой.
- Финальный сквозной прогон: ноль pageerror, ноль HTTP-ошибок ресурсов. integration-results.json и integration-run.txt.
- Контролируемое близкое столкновение настоящих бойцов в ангаре: 0 ошибок JavaScript; у выбранных AK-74 3 и 4 выстрела, боезапас 30→27 и 30→26; всего AI зарегистрировал 40 выстрелов, один из выбранных бойцов погиб. Это искусственная постановка близкого огневого контакта, не тест естественного развития боя. fire-results.json и fire-run.txt.
- Изолированный AI: 10 проверок видимости, cooldown, исключения управляемого бойца, союзника на линии, погибшей цели и обхода препятствия. Контроллеры в этом тесте подменены. combat-run.txt.
- Баллистика/медицина/сопротивление: 499 assertions, ballistic-final.log.
- Пространственная трассировка после правки спрайтов: 3000 совпадений с native raycast, trace-final.log.
- Физика бойцов: 180 сценариев, ноль неудач, rig-final.log. Это регрессия физического стенда, не доказательство всех коллизий каждой карты.

## Исправлено при проверке
- FRAME включён в зависимое окружение лесных карт: без него первый запуск был возможен, но обновление мира давало исключение.
- Декоративные световые спрайты ангара исключены из физической трассировки: иначе Sprite.raycast ожидал камеру и прерывал проверку видимости AI.
- Проверка расхода использует mag/chamber/reserve, а не производное поле ammo; иначе тест сам некорректно задавал состояние.

## Не подтверждено
- Игровой FPS и 1% low на слабых Intel/AMD/NVIDIA, длительный бой и стабильность многочасовой сессии.
- Массовые бои 40/80 бойцов, все варианты экипировки/обвесов, все маршруты/перепады высоты и разрушаемость каждого объекта.
- В естественном четырёхсекундном сквозном прогоне боя выстрелов не было: дальность/укрытия стартовых баз не позволили установить огневой контакт. Нельзя выдавать этот прогон за доказательство полноценной перестрелки и баланса AI.
- Геометрия и материалы карт перенесены, но старые движки физики/разрушения не перенесены; освещение AEGIS отличается.

## Воспроизведение
В корне игры: python3 -m http.server 8765. Для browser-тестов нужны Node, Playwright и Chromium; для Node-регрессий — только Node. Примеры:

```
node tools/map-tests/integration.cjs
node tools/map-tests/fire-test.cjs
node tools/map-tests/combat-regression.cjs
node tools/ui-tests/run-ui.cjs
node tools/ballistics_regression.js
node tools/trace_regression.js
node tools/rig_physics_regression.js
```

Прочие старые отчёты в tools/ унаследованы и не подтверждают новые карты. Этот отчёт и приложенные свежие результаты имеют приоритет.
