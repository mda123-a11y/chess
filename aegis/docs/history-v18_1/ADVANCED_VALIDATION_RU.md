# Проверка AEGIS 18.1

Это новая итерация после первой экспериментальной миграции. Результаты первой версии отделены в `tools/advanced-tests/history-v1/`; их нельзя приписывать текущим движениям и медицинскому дереву.

## Численные проверки

- `npm run typecheck` — строгая проверка TypeScript всех шести новых модулей.
- `npm test` — BT/очередь A*/память/LOS/запрет огня через союзника; коллизии капсулы; 36 падений (четыре модели × 60/30/20 Гц × уклоны 0/±0,12); ограниченность координат/длин сегментов и углов шарниров; освобождение тел при оживлении.
- Добавлен `continuation.cjs`: перелезание через низкий бокс на 60/30/20 Гц, отказ под низким потолком, прерывание при появлении стены, проверка тонкого препятствия между узлами навигации, падение физического предмета/очистка, сходимость PD-привода, выбор союзника/резервирование медика/исключение игрока.
- Старые независимые тесты: 499 утверждений баллистики/медицины и 3000 совпадений лучей проходят. Они не заменяют новые проверки Rapier и игрового поведения.

`checks` в `results.json` включает проверки каждой координаты на каждом шаге. Это не миллион независимых игровых сценариев. Допуски длины сегментов не доказывают анатомическую точность всех поз.

## Браузерные сценарии

Стенды используют реальные модели/контроллеры/игровой цикл в Chromium. Для CPU-проверок отрисовка и предварительная компиляция сцены отключаются только перехватом ответа на тестовой странице; файлы игры на диске не меняются.

- `continuation-browser.cjs`: 12 бойцов × пять поз = 60 сочетаний. Проверяются конечность костей и реальные `palmR/L`, `wristErrorR/L`, а не условные поля. Есть 180 шагов движения штатной модели на ровной поверхности, расстояния от стоп до запланированных точек и граната через настоящий `GSIM` с удалением тела.
- `medical-browser.cjs`: два союзника в реальной сцене «Ангара»; контрольный лежащий раненый с одним заданным артериальным источником. Для обоих бойцов выбирается свободная ровная площадка (пациент не должен стартовать внутри ящика). Медик подходит, достигает кистями места помощи и накладывает жгут; проверяется `tq` источника и расход ровно одного жгута. Автоматический респаун на время стенда удерживается. Без оружия и с АК-74 проверяются отдельно (`ARMED=1`). Это не бой под огнём и не клиническая валидация всей физиологии.
- `browser-smoke.cjs`: 12 вооружённых бойцов на каждой из трёх карт, контроль хвата NPC и координат; скрытое тело управляемого персонажа в FP исключается из проверки этого хвата (все 12 моделей отдельно проверены через `poseStand`); отдельная принудительно размещённая дуэль с реальными выстрелами; контрольный collapse и дальнейшая динамика тела. Скрипт возвращает ошибку при нарушениях.
- `visual-smoke.cjs`: настоящая отрисовка стоя/с колена/лёжа/после падения. Окружение скрыто, чтобы рассмотреть персонажа; сетка — ориентир, не подмена физики карты. Кадры: `visual-*.png`.

JSON этих сценариев сохранены рядом со стендами. Подробные результаты и точные границы не следует заменять фразой «вся игра полностью протестирована».

## CPU: что действительно ускорено

Исходный профиль выявил горячий участок: `27_game_flags.js` (ткань и многократные запросы ветра). Дополнительно уменьшены повторные запросы неподвижных капсул, введены бюджеты навигации, сон сошедшихся позовых приводов и кэш неподвижных ног. Последний допускает малые изменения матрицы и перепроверяется не реже 5 Гц; при ходьбе он не используется.

Контроль: качество low, полигон, четыре невооружённых NPC, **без отрисовки**, 90 шагов прогрева + 900 измеряемых шагов 1/60; отдельные Chromium-сессии, sampling profiler. Исходные файлы взяты непосредственно из приложенного архива; добавлены только измерения и отключение рендера в стенде.

| Показатель, мс | Исходник, повтор | Текущая версия |
| --- | ---: | ---: |
| Средний полный CPU-шаг | 1,592 | 1,444 |
| Медиана | 1,600 | 1,200 |
| p95 | 3,500 | 3,800 |
| Флаги, среднее последних 360 шагов | 0,751 | 0,287 |

В этой паре средний CPU-шаг дешевле примерно на **9,3%**, но p95 **хуже**. Более ранний исходный прогон дал 1,787 мс среднего и 4,0 мс p95 — заметна вариативность. Промежуточная новая версия до оптимизации неподвижных ног была медленнее исходника. Не обещается устойчивый выигрыш на любом железе.

Это **не FPS-тест** и не оценка GPU, боевой толпы, длительных сражений или frame pacing реального рендера. Общая сложность новой физики имеет цену. Старые 15,4% из первой итерации не используются как результат 18.1.

Актуальные файлы: `cpu-v2-updated.json`, `cpu-v2-baseline-repeat.json`, `cpu-v2-baseline.json`, `performance-summary.json`. Исторические промежуточные данные лежат в отдельных папках.

## Как повторить

Запустить сервер из `AEGIS`, установить Playwright для тестов и его Chromium либо указать `CHROMIUM_PATH`. Npm и Playwright не нужны для обычного запуска игры.

```sh
npm ci
npm run build
npm run typecheck
npm test
BASE_URL=http://127.0.0.1:8000/ node tools/advanced-tests/continuation-browser.cjs
BASE_URL=http://127.0.0.1:8000/ node tools/advanced-tests/medical-browser.cjs
BASE_URL=http://127.0.0.1:8000/ ARMED=1 node tools/advanced-tests/medical-browser.cjs
BASE_URL=http://127.0.0.1:8000/ MAP=angar_map node tools/advanced-tests/browser-smoke.cjs
BASE_URL=http://127.0.0.1:8000/ node tools/advanced-tests/compare-cpu.cjs
```

Для исходника распаковать исходный ZIP в другую папку и задать `ORIGINAL_DIR=/путь/к/исходной/AEGIS BASELINE=1`. `compare-cpu.cjs` берёт исходный загрузчик/контроллер/урон/гранаты/медицину/флаги из этой папки и подставляет их в тестовый ответ. Для второго прогона убрать `BASELINE` и `ORIGINAL_DIR`. Прогоны выполнять последовательно, без других браузерных тестов одновременно.

## Не завершено / не подтверждено

- Живой скелет — локальные угловые Rapier-приводы + IK и капсульное перемещение, **не полностью контактный active ragdoll** с физическими мышцами и столкновениями каждой живой конечности с миром.
- Новые анимационные клипы, motion matching, симуляция всей одежды и полная замена каждого визуального/физического эффекта не выполнены.
- Подход к раненому на сложных возвышениях/внутри геометрии не гарантирован; недостижимые частичные маршруты отклоняются с временным исключением цели.
- Волочение на скоростях Rapier реализовано, но эвакуация под огнём, тесные проходы с телом, все раны и составы группы не прошли полную регрессию.
- Перелезание проверяет движение капсулы и перенос ног; полноценная контактная опора кистями на край препятствия не реализована.
- Навигация — ограниченный A*, не Recast navmesh: многоэтажные связи, подвижные платформы и полноценные off-mesh links не реализованы.
- Не пройдены длительные автономные сражения всех карт, все оружия/экипировки и реальные слабые GPU. Обычный десятисекундный старт с баз не доказывает завершённый бой.
- Проверенный запуск — HTTP. Полный прогон `file://` не выполнен.
