## Как читать контактные метрики

- `maxGap` / `maxJointGap` измеряет расстояние между якорями физического сустава, **не** погрешность всех вершин кожи.
- `maxHandError` в тесте перелезания — расстояние запястья до интерполированной IK-цели. Малое значение доказывает геометрическое ограничение кисти, но не физическое удержание веса тела руками.
- `maxFPError` проверяет совпадение опорных точек двух визуальных представлений кисти. Это не доказательство отсутствия любого пересечения рукава с окружением.
- Внутренний `maxAngle` контактного рига может быть большим во время переноса; обратная связь при расхождении от 0,9 рад блокируется. Не выдавайте это значение за анатомический диапазон сустава живой модели.
- Приводы и суставы физические, но корень управляет KCC. Нет самостоятельного баланса и безусловной физической поддержки всей массы на краю.

## CPU: подтверждённый узкий участок и исправление

Ранний профиль 18.2 с точным неускоренным зрением (`history-v3-before-final/soak-angar-exact.json`) показывал большую долю `getVertexPosition`, `_computeIntersections`, чтения координат и проверок треугольников Three. В бою это важнее прежнего спокойного теста ткани.

Частое зрение перенесено на Rapier raycast по статическим коллайдерам. Точная баллистика не подменена этими упрощёнными коллайдерами: у неё остаются исходные треугольники, материал и проникновение, ускоряемые локальным BVH. Массивы материалов идут по исходной трассировке из-за несовместимости upstream indirect-режима; тест специально проверяет сохранение материала/грани/экземпляра. Skinned/morph/cloth исключены из построения дерева.

`trace-bvh.json` содержит **три повторения одинаковых 400 лучей по плоскости 64 800 треугольников**. Точные времена каждого повтора сохраняются в JSON; время построения дерева в этот микрозамер не входит. Это специально плотный микротест, преимущество зависит от сцены. Не пересчитывайте его в ускорение всей игры.

В текущих 90-секундных браузерных прогонах записываются:
- время всего пакета из 120 игровых шагов;
- отдельные тайминги ограниченного буфера **последних 360 измерений**;
- sampling CPU-профиль и список горячих функций;
- фактические события боя и число физических тел.

Качество low, Chromium в песочнице, **без отрисовки**, с sampling profiler. `simulation.mean` относится к последним 360 шагам, а не ко всем 5400. Не сравнивайте его напрямую с микротестом, со старым четырёхботным полигоном или с усреднением другого участка боя. Случайные спавны/подавление/путь влияют на нагрузку; контролируемого общего процента ускорения относительно v17 для всех боевых карт здесь нет.

Новые риги добавляют стоимость Rapier; их число ограничено. После ускорения лучей заметными остаются физика, запросы Detour, матрицы, анимация и оружейные пружины. Старые показатели 18.1 сохранены только как история. Текущие CPU-результаты **не являются FPS**, оценкой GPU или гарантией frame pacing реального рендера.

## Воспроизведение

Сервер запускать из корня `AEGIS`. Node 22+, `npm ci`, `npm run build`, `npm run typecheck`, `npm test`. Для браузерных стендов отдельно установить Playwright/Chromium, запустить HTTP-сервер и задать `BASE_URL`. При необходимости указать `CHROMIUM_PATH`. **Не запускать браузерные стенды одновременно** на малой памяти.

```sh
BASE_URL=http://127.0.0.1:8000/ node tools/advanced-tests/combat-aim-browser.cjs
BASE_URL=http://127.0.0.1:8000/ node tools/advanced-tests/quality-v3-browser.cjs
BASE_URL=http://127.0.0.1:8000/ ARMED=1 node tools/advanced-tests/quality-v3-browser.cjs
BASE_URL=http://127.0.0.1:8000/ node tools/advanced-tests/continuation-browser.cjs
# Для медицинского теста отдельно все четыре сочетания ARMED / BARRIER.
BASE_URL=http://127.0.0.1:8000/ BARRIER=1 ARMED=1 node tools/advanced-tests/medical-browser.cjs
# Повторить обе проверки для angar_map, forest_map_camp, stroyka_zarechye_v2.
BASE_URL=http://127.0.0.1:8000/ MAP=angar_map node tools/advanced-tests/browser-smoke.cjs
BASE_URL=http://127.0.0.1:8000/ MAP=angar_map SOAK_SECONDS=90 node tools/advanced-tests/soak-browser.cjs
```

CPU-стенды перехватывают ответ только своей страницы и выключают рендер/прогрев шейдеров; игровой файл на диске не заменяется. Поэтому `pageerror=[]` в них не доказывает исправность всех графических эффектов. Визуальный стенд использует настоящий renderer отдельно.

## Что не доказано и не перенесено

Девяносто секунд боя на каждой карте — расширенная регрессия, не многочасовой QA. Стрельба в дальнем лесном контакте не обязана приводить к поражению за этот срок. Зафиксированные недостижимые/частичные пути не скрываются и не означают полноту навигации. Нет автоматических паркурных/moving-platform связей и самостоятельного равновесия тела, полного физического подвеса на руках, нового motion capture, проверки каждой раны/оружия/экипировки, всех случаев эвакуации и реальных слабых GPU. Частные эффекты, ткань, отдача, гильзы и баллистика остаются специализированными. Проверен HTTP, не полный `file://`-прогон.

## Новые правила проверки навигации

Recast строится плитками 96 × 96 вокселей в worker по физическим поверхностям, а не по LOD визуальных мешей. Геометрия цилиндров консервативна; erosion/вокселизация добавляют запас. Значение `complete` означает соединение проецированных полигонов и близость конечной точки к запросу, а не телепортацию персонажа. `projected` означает достижимую ближайшую точку, не точное попадание в исходную цель. `partial`/`unreachable` остаются допустимыми исходами, но не выдаются за успех.

При запросах на разных этажах сравнивается высота. Сетевая память противника сохраняет наблюдавшуюся Y, лечебный маршрут не заменяет её `heightAt`. Для утверждения о физическом подъёме используются отдельные тесты KCC и клиническая платформа: одного списка точек Detour недостаточно.

`navigation.json` также фиксирует размер WASM heap до/после 10 000 запросов. Это проверка освобождения массивов запросов в одном процессе, не доказательство отсутствия всех утечек всей игры. Память построения освобождается завершением worker. Перестройка при разрушении заменяет старую сетку только после успешного импорта новой.

Дополнительно: `BASE_URL=http://127.0.0.1:8000/ ELEVATED=1 ARMED=1 node tools/advanced-tests/medical-browser.cjs`; для покрытия спавнов — `MAP=angar_map node tools/advanced-tests/navigation-browser.cjs` с тем же BASE_URL. История 18.2 — `docs/history-v18_2/`.

В сборщике плиток исправлена отдельная ошибка upstream: плитка с успешно построенной геометрией, но нулём проходимых полигонов возвращается как пустая до createNavMeshData. Реальные RC_LOG_ERROR и неудачный addTile отклоняют всю новую сетку; неудачные плитки не пропускаются молча. Оригинал генератора и описание патча сохранены в vendor/recast/.

Дальняя пара лесных баз в первом Recast-прогоне исчерпывала 8192 узла (DT_OUT_OF_NODES), а не была физически разорвана водой. Финальная ёмкость — 32768 узлов; повторное покрытие спавнов сохранено отдельно. Увеличение лимита не доказывает бесплатность поиска: CPU-стоимость и числа неполных запросов сохраняются в итоговом отчёте.
