1. КАК МУЗЫКА ВЛИЯЕТ НА ТРАФИК
====================================================================
 - Эмоция: один и тот же кадр под фонк = "сила", под пианино = "трагедия". Музыка задаёт, ЧТО чувствовать.
 - Ритм: склейки в бит держат внимание (мозг предсказывает удар и получает награду).
 - Звук-тренд: в TikTok и Shorts у каждого звука есть своя страница со всеми роликами на этот звук.
   Ролик на трендовый звук получает шанс показа тем, кто "залип" на этот звук.
 - Узнаваемость: знакомый трек = "о, это та самая песня", дольше смотрят, пишут в комментариях название.
 - Пересмотры: короткий цепляющий кусок трека хочется переслушать (петля).

3. КАРТА "ЭМОЦИЯ -> ЖАНР -> ПРИМЕРЫ"
====================================================================
Примеры = известные треки, которые массово используются в эдитах (часть найдена в поиске YouTube
12.10.2026 с числом просмотров). Тренды меняются: перед роликом проверяй актуальность по разделу 6.

 СИЛА / СИГМА / "AURA" / ХОЛОДНЫЙ ВЗГЛЯД
   Жанр: phonk (дрифт-фонк, cowbell, дисторшн-бас), brazilian phonk/funk ("montagem"), hard trap.
   Примеры: Kordhell - Murder In My Mind; DVRST - Close Eyes; INTERWORLD - Metamorphosis;
   Hensonn - Sahara; "Voce na mira (super slowed)" (5.2 млн на YouTube, edit audio);
   "No batidão (ultra slowed)" (4.3 млн); "X-COOL! (TikTok version)" (1.4 млн).
   BPM 120-160 (или slowed). Монтаж: резко, тряска, зум-удары.
 ЗЛОДЕЙ / ТЬМА / ПСИХОЛОГИЯ (Джокер, Бейтман)
   Жанр: darkwave, slowed синти, мрачный пост-панк.
   Примеры: Mr.Kitty - After Dark; MGMT - Little Dark Age; VØJ, Narvent - Memory Reboot.
 ПЕРЕРОЖДЕНИЕ / ГЛОУ-АП / "КРУТОЙ"
   Жанр: slowed поп и хаус-классика, funk.
   Примеры: Stromae - Alors on danse (slowed); Gym Class Heroes - Stereo Hearts (edit audio, 25 млн);
   Panic! At The Disco - House of Memories (edit audio, 15 млн).
 ТРАГЕДИЯ / ГРУСТЬ / ПОТЕРЯ / SAD EDIT
   Жанр: пианино, slowed + reverb, инди-фолк, грустный поп.
   Примеры: Coldplay - Hymn for the Weekend (sad edit audio, 10 млн); Sufjan Stevens - Fourth of July;
   Tom Odell - Another Love; MIIA - Dynasty (slowed, 1.7 млн).
 ОДИНОЧЕСТВО / ЛЮБОВЬ / ФИЛОСОФИЯ
   Жанр: мягкая гитара/пианино, классический рок-баллады.
   Примеры: Sting - Shape Of My Heart; Ludovico Einaudi - Experience; Yann Tiersen - Comptine d'un autre ete.
 ЭПИК / ИСТОРИЯ / ВОЙНА / МОТИВАЦИЯ "ГЕРОЙ"
   Жанр: cinematic orchestral, трейлерная музыка, epic remix.
   Примеры: Paul Ameller - Feeling Good (EPIC VERSION, 13 млн); John Murphy - Adagio in D minor
   (Sunshine, 4.4 млн); Really Slow Motion - Deadwood (67 млн); Hans Zimmer - Time.
 РОМАНТИКА / ПАРА
   Жанр: slowed R&B, инди-поп.
   Примеры: The Neighbourhood - Sweater Weather; The Weeknd - Die For You (slowed).
 ТАЙНА / ТЕОРИИ / ПРЕДСКАЗАНИЯ / ХОРРОР-ФАКТЫ (формат Starikov)
   Жанр: dark ambient, дрон, тиканье часов, органные пады, низкий гул. Без вокала (под голос).
 ДЕНЬГИ / УСПЕХ / БИЗНЕС ("я заработал")
   Жанр: lo-fi trap, бодрый хип-хоп инструментал, "luxury" бит, "звук денег" (касса) как акцент.
 ЮМОР / POV / МЕМЫ
   Мем-звуки и короткие треки-тренды (TikTok-звуки недели), vine boom, "record scratch", тишина-пауза.
 Правило: если ролик говорящий, трек без вокала (вокал спорит с голосом). В эдите вокал разрешён.

4. КАК ИСКАТЬ ХАЙПОВЫЕ ТРЕКИ НА YOUTUBE
====================================================================
4.1 Запросы, которые реально работают (проверено поиском 12.10.2026)
   "edit audio"                          -> отдельные треки "[трек] [edit audio]" и подборки
   "phonk edit audio"                    -> подборки "35+ phonk/funk edit audios ... +timestamps" (176 тыс. за 6 дней)
   "edit audios that make you feel powerful" -> подборки "main character", "final battle" (до 6.8 млн)
   "sad edit audio slowed"               -> "Sad/Vent audios", "Sad Edit Audios because life is unfair"
   "cinematic edit audio"                -> эпик-подборки
   "[название трека] edit audio" / "[трек] slowed" / "[трек] best part" / "[трек] tiktok version"
   "аудио для эдитов" (выдаёт в основном англоязычные подборки, они и есть мировой тренд)
   Шаблон подборок, по которому их ищут: "[число]+ [настроение] edit audios + timestamps".
4.2 Как читать результаты
   - Фильтр "Дата загрузки: за эту неделю / этот месяц" -> что слушают СЕЙЧАС.
   - Свежая подборка (2-7 дней) с 50-300 тыс. просмотров = в ней трендовые звуки. Открывай таймкоды
     и выписывай треки, которые повторяются в 2-3 разных подборках.
   - Одиночное "[трек] [edit audio]" с миллионами просмотров за 1-3 месяца = звук на пике.
   - С миллионами за 3-5 лет = "вечнозелёный" (надёжно, но не тренд).
   - Комментарии с таймкодами ("2:31 это что за трек?") показывают, какие куски цепляют.
4.3 Через Shorts
   - В Shorts нажми на название звука внизу (иконка ноты) -> страница звука: исходное видео и все Shorts
     на этот звук. Много свежих Shorts на звук = тренд.
   - Кнопка "Remix -> Звук": взять звук из чужого Shorts/видео (при загрузке через приложение).
   - YouTube Create / редактор Shorts в приложении показывает популярные треки.
4.4 Эдит-каналы как радар
   Подпишись (с отдельного аккаунта для ресёрча) на 20-30 эдит-каналов в нише (кино, аниме, спорт).
   Названия их эдитов обычно содержат трек ("| Stromae - Alors on danse (slowed)"). Выписывай треки,
   которые повторяются у разных авторов за неделю.

5. ГДЕ ЕЩЁ ИСКАТЬ
====================================================================
 - TikTok Creative Center (ads.tiktok.com/creative/creativeCenter -> Trends -> Songs):
   топ треков по региону (выбрать Россия/США) за 7 или 30 дней, рост популярности, пометка
   "breakout" (новый взлёт). Для бизнес-аккаунтов там же видно, что разрешено в коммерческой библиотеке.
 - TikTok: страница звука (число роликов), раздел "Звуки" при загрузке, вкладка "Популярное".
 - CapCut: шаблоны (templates) с пометкой trending и названием трека; раздел "Звуки" -> "В тренде".
 - Spotify: плейлисты "Phonk for edits", "edit audios", "Viral 50" по странам.
 - Instagram Reels: значок стрелки "тренд" рядом с названием аудио.
 - Бесплатные библиотеки (для фоновой музыки под голос): Фонотека YouTube (YouTube Studio -> Фонотека),
   Pixabay Music. Для звуковых эффектов: freesound.org, Фонотека YouTube.

6. КАК ПОНЯТЬ, ЧТО ТРЕК В ТРЕНДЕ
====================================================================
 Хороший сигнал (2+ пункта):
  [ ] звук в 2-3 свежих подборках "edit audios" за последние 7 дней
  [ ] на странице звука в Shorts/TikTok много роликов за последние дни
  [ ] в Creative Center растёт (стрелка вверх или breakout)
  [ ] у эдит-авторов в нише 3+ ролика на этот трек за неделю
 Окно тренда: обычно от нескольких дней до 2-3 недель. Опоздал = звук "умер", лучше вечнозелёный.
 Стратегия: 70% роликов на проверенные вечнозелёные треки под эмоцию, 30% на свежие тренды (тест).

7. КАК ВЫБРАТЬ КУСОК ТРЕКА
====================================================================
 - Ищи "best part": место, где трек взрывается (дроп, припев, вход баса). Обычно его и вырезают
   в "edit audio" версиях. Многие edit audio уже начинаются за 2-6 с до дропа.
 - Для эдита A (реплика -> дроп): трек начинается тихо под репликой, дроп = конец реплики.
   Если реплика 3.5 с, а дроп трека на 6.86 с, то музыка стартует на 3.36 с раньше видео (offset).
 - Начало ролика на сильной доле или на вокальной фразе, не посередине такта.
 - Конец ролика на сильной доле, без затухания (петля).
 - Длина куска = длина ролика. Не растягивай ролик ради всего трека.
 - Если в треке пауза перед дропом: оставь её (тишина 0.2-0.5 с усиливает удар).
 - В скилле: `beats файл|URL` даёт темп, доли и энергию; `audio.music.drop_at`, `audio.music.offset`,
   `audio.music.pre_drop_db` в плане.

8. СВЕДЕНИЕ (ГРОМКОСТЬ)
====================================================================
 Ситуация                         | Музыка относительно голоса     | Комментарий
 Говорящая голова / пересказ      | на 15-20 дБ тише голоса         | голос всегда понятен
 Монолог из фильма                | на 12-18 дБ тише               | подложка, не песня
 Эдит до дропа (реплика)          | около -16 дБ к голосу (скилл)   | реплика понятна
 Эдит после дропа                 | музыка главная, 0 дБ            | голоса нет
 Ducking: музыка автоматически проседает на голосе и поднимается в паузах (скилл: duck_db).
 Итог ролика: около -14 LUFS, пик не выше -1 dBTP (YouTube и другие платформы нормализуют громкость,
 слишком тихий ролик звучит слабее соседних в ленте).
 Голос: убрать шум, лёгкая компрессия, нижние частоты до 80 Гц срезать.

9. ЗВУКОВЫЕ ЭФФЕКТЫ (SFX)
====================================================================
 Эффект          | Где ставить                                  | Громкость
 whoosh / swish  | быстрые переходы, вылет текста               | -16..-14 дБ
 riser           | 0.5-1.5 с перед дропом или раскрытием         | нарастает до -12
 hit / impact    | дроп, появление числа, панч                   | -10..-8
 braam (трейлер) | "вау"-момент, раскрытие тайны                 | -10
 sub drop        | смена мира, переход в кульминацию             | -12
 pop / click     | появление текста, кнопки, списка              | -18..-14
 camera shutter  | стоп-кадр                                     | -14
 касса / монеты  | деньги в кадре или в речи                     | -14
 сердцебиение    | напряжение, страх                              | -18
 тиканье часов   | дедлайн, "время уходит", тайна                 | -20
 record scratch  | "стоп, что?", юмор                             | -14
 тишина          | перед панчем (0.2-0.5 с)                       | -
 Правило: SFX по смыслу или на ключевом событии, не на каждой склейке. 4-10 эффектов на 20-40 с.
 В скилле есть свои CC0 звуки: click, tick, pop, whoosh, hit, riser, shutter; `scenes[].sfx`.

10. ГОТОВЫЕ РЕЦЕПТЫ ЗВУКА ПО ФОРМАТАМ
====================================================================
 Эдит (сила):        фонк/brazilian phonk, реплика 2-5 с -> riser -> дроп + hit + flash.
 Эдит (трагедия):    slowed пианино или грустная песня, без hit, мягкий whoosh, кроссфейды.
 Монолог из фильма:  оригинальный голос + эпик/пианино на -15 дБ, в конце на панче подъём музыки.
 Философия:          оригинальный голос + грустная песня (Sting, Sufjan) очень тихо, ч/б картинка.
 Пересказ/рекап:     голос + напряжённый инструментал без вокала, смена трека на повороте сюжета.
 Теории/тайны:       голос + dark ambient + тиканье, hit на "самое странное".
 Деньги/успех:       голос + бодрый trap-бит без вокала + касса на цифрах.
 POV/юмор:           трендовый мем-звук недели, тишина-пауза перед панчем.

11. ОШИБКИ
====================================================================
 1. Один и тот же трек во всех роликах канала.
 2. Весёлая музыка под грусть или наоборот.
 3. Песня с вокалом под говорящий голос.
 4. Музыка громче речи.
 5. Затухание (fade out) в конце эдита вместо обрыва на доле.
 6. Дроп не совпал с важным событием в кадре.
 7. Трек "умер" (тренд прошёл), а его ставят как свежий.
 8. Начало трека с длинного тихого интро (5+ с ничего не происходит).

12. АЛГОРИТМ ВЫБОРА МУЗЫКИ ДЛЯ ИИ
====================================================================
 1) Определи эмоцию ролика одним словом и формат (говорящий / эдит / монолог).
 2) По таблице раздела 3 выбери жанр и 3 кандидата.
 3) Если есть доступ к YouTube: поиск "[эмоция] edit audio" с фильтром "за неделю" и
    "[кандидат] edit audio", выпиши треки, которые повторяются; отметь просмотры и дату.
 4) Говорящий формат -> только инструментал. Эдит -> трек с явным дропом 120-160 BPM (или slowed).
 5) Найди дроп и сильные доли (`beats`). Подгони offset так, чтобы дроп = событие (конец реплики).
 6) Сведение по разделу 8, SFX по разделу 9.
 7) В подписи и закрепе укажи трек (люди спрашивают название, это комментарии).
 8) Если трек не дал пользователь: дефолт скилла или версия без музыки + music cue, а трендовый
    звук добавить из фонотеки площадки в приложении (раздел 13).
 9) Записать трек (или "добавлен в приложении") в memory/sources.md.

13. ТРЕНДОВЫЙ ЗВУК ИЗ ФОНОТЕКИ ПЛОЩАДКИ И ВЕРСИЯ БЕЗ МУЗЫКИ
====================================================================
 - Звук, добавленный в приложении площадки (фонотека Shorts, звуки TikTok, аудио Instagram),
   привязывает ролик к странице звука: оттуда идут дополнительные показы, а тренд виден по
   числу роликов на звуке (раздел 6). [О]
 - Фонотека Shorts: трек до 90 с (зависит от трека). TikTok: у бизнес-аккаунта только
   Commercial Music Library, часть трендовой музыки недоступна (файл 18, раздел 1). [П]
 - Схема для скилла: рендер с треком для предпросмотра + версия без музыки и music cue
   ("трек X с 0:12, дроп на 0:07 ролика"); трек ставится в приложении площадки. [ТЗ, файл 14]
