2. УПАКОВКА ДЛИННОГО: 4-ЭЛЕМЕНТНАЯ СИСТЕМА
====================================================================
 Длинное продают ОБЛОЖКА + НАЗВАНИЕ (CTR), удерживают ХУК + ИНТРО. Это одна система
 обещаний (overseeros, файл 25):
  НАЗВАНИЕ  = словесная версия core question ("почему этот ролик важен");
  ОБЛОЖКА   = визуальная версия вопроса (заставляет остановиться);
  ХУК (0-5 с) = самое быстрое подтверждение, что клик был верным;
  ИНТРО (5-30 с) = мост в историю/аргумент + причина смотреть дальше.
  Зритель судит клик до 30 с: если хук меняет обещание - трение и обвал.
 Требования к элементам:
  - Название: 65-70 символов (10-11 слов), числа встречаются в 32-40% топа; причинный прирост CTR не установлен,
    вопросы - слабее, эмодзи - редко [Д 2025, subsub; файл 25, правки к 07].
  - Обложка: 1 объект, 0-4 слова текста, тест 150 px, CTR ниже 3% стабильно - чинить
    обложку (файл 25, правки к 06). A/B: Test & Compare, до 3 вариантов, победа по
    времени просмотра (файл 21, р.7).
  - Бенчмарки CTR: канал 2-10%, 4-6% - уверенно; сравнение со СВОИМ средним (файл 25).

3. ПЕРВАЯ МИНУТА ПОМИНУТНО
====================================================================
 Самая дорогая минута ролика. Ориентир масштаба (MrBeast, слитый внутренний документ):
 потерять 21 млн зрителей из 60 млн кликов в первую минуту - ХОРОШИЙ результат; то есть
 даже топ-каналы теряют треть зрителя в первую минуту, задача - не потерять больше.
 0:00-0:05  ПОДТВЕРЖДЕНИЕ КЛИКА: показать то, что обещали обложка и название.
            В форматах С ГОЛОСОМ голос с первой секунды (43 из 50 свежих видео крупных
            каналов начинают голос сразу; файл 25, правки к 09). Без логотипа, без
            "привет, с вами...". В бессюжетных/безголосых форматах (клип-эдит, видеоэссе
            под музыку, монтаж-коллаж) подтверждение делает ВИЗУАЛ и текст на экране -
            правило голоса НЕ применяется (условная маршрутизация по формату, файл 02).
 0:05-0:30 СТАВКИ: зачем смотреть до конца ("в конце покажу самое безумное"),
            масштаб/ценность ("это изменило мою..." / "ты теряешь...").
 0:30-1:00 ПЕРВЫЙ РЕЗУЛЬТАТ: быстрый факт/эпизод, доказывающий, что обещание
            выполнят (зритель должен поверить в payoff).
 Правила:
  - Первая минута решает, покажет ли YouTube ролик дальше (MrBeast; файл 10, р.1).
  - Холодное начало (in medias res) с самым странным фактом - стандарт документалок
    (файл 16, р.11).
  - Никаких заставок: "вступление" = место в рекомендуемых, а не ролик.

4. МОДУЛЬНАЯ СТРУКТУРА: БЛОКИ 3-7 МИНУТ
====================================================================
 Пробный каркас [Г], не канон любого жанра (по datafield, файл 25): длинное = последовательность блоков 3-7 минут,
 каждый блок - мини-видео со своим ХУКОМ, КОНТЕНТОМ и PAYOFF.
  - Переход между блоками = ресет внимания: смена локации/темы/визуального режима
    (возвращение ориентировочного рефлекса).
  - Кривая удержания длинного - волны: подъём на хуке блока, спуск к его payoff,
    следующий блок поднимает снова. Провалы на стыках тоже требуют разбора контекста; внутри блока -
    чинить блок.
  - Главы (таймкоды в описании, файл 08, р.3) = мини-сценарии, каждая со своим
    вопросом и ответом (файл 09, р.7).
  - Структура-пример 5 блоков (~20-минутному ролику: 3-7 мин х 5 = 15-35 мин; для 2 ч
    ролика блоков 15-25, не 5): хук-блок 3-5 мин -> углубление 5-8 -> середина (2-й по силе
    момент) -> поворот -> развязка + payoff.
  - Правила этого файла написаны для речевых форматов (разбор, видеоэссе, документалка).
    Для безголосых жанров (клип, эдит-коллаж) часть правил не применяется: "ответ только
    в конце" и "голос с 1-й секунды" работают только когда есть нарратив; у клипа ставкой
    становится визуальная интрига и дроп. Выбирай правила ПО ФОРМАТУ, не механически.
 Таблица планирования блока:
  Блок | Мин | Хук блока (1 фраза) | Контент | Payoff блока | Переход (re-hook)

5. ПРОГРЕССИЯ ТЕМПА ПО МИНУТАМ
====================================================================
 Пробный каркас [Г], не канон любого жанра (air.io, файл 25, правки к 16) - вместо ровных "5-15 с" файла 16:
  - 0-3 мин: плотно, визуальная смена каждые 10-20 с (зритель ещё не доверяет);
  - 3-7 мин: шире, 25-40 с (доверие заработано, можно дышать, больше B-roll с контекстом);
  - после 8 мин: спокойные объяснения + короткие всплески энергии (реакция, цифра на
    экране, эмоциональный бит). Ритм: стимул -> покой -> снова стимул.
  Правило: замедлять по мере погружения, но не давать застоя (провис, файл 16, р.1).
  Смена "чего-то" (кадр, графика, звук, локация, вопрос) каждые 5-15 с остаётся
  одним из вариантов для эссе [Г], не нижней границей; паттерн-интеррапт 20-40 с в длинном (файл 16, р.10).

6. ОТКРЫТЫЕ ПЕТЛИ И RE-HOOKS
====================================================================
 - Открытая петля в первые 5 с ("в конце - самое безумное") + обязательное выполнение.
 - Re-hook каждые 60-90 с: "но это было не самое странное", "а дальше всё пошло не так"
   (файл 09, р.7). В блочной структуре re-hook = хук следующего блока.
 - Прогресс-ощущение: "первое... второе... третье" - зритель знает, сколько осталось
   (файл 10, р.6, приём 13).
 - Каждая глава заканчивается полу-ответом, который открывает следующий вопрос.

8. КОНЕЦ: PAYOFF, ПЕРЕХОД, END SCREEN
====================================================================
 1. ГЛАВНЫЙ PAYOFF по жанру, не обязательно в конце (длинное: ответ на core question) - как обещали в 0:05-0:30.
 2. Вывод/эмоция: 5-15 с, одна мысль (не растягивать).
 3. Переход на следующее видео без "ну вот и всё": вопрос в комментарии / "часть 2" /
    следующая тема одной фразой.
 4. End screen 5-20 с: следующее видео, плейлист или подписка (файл 11, р.8). Последние
    5-20 с строить так, чтобы там не было важного контента (файл 09, р.7).
 5. CTA: подписка - упаковкой "будет ещё" (серия, следующая тема; наша основная гипотеза
    [Г], подкреплённая практиками), лайк - коротко на пике в середине (файл 25, правки к 11);
    в исследовании [Д 2025 JRIM, ограниченно: одна англоязычная выборка] значимого эффекта
    просьбы "подпишись" не найдено - это не запрет, а повод не строить на ней механику.

10. ЧЕК-ЛИСТ И ПРОМПТ ДЛЯ ИИ
====================================================================
 Чек-лист:
  [ ] Core question сформулирован; название+обложка+хук+интро = одна система обещаний
  [ ] Название соответствует реальному обещанию; 65-70 симв. - сторонний ориентир,
      число и вопрос только по смыслу [Г]
  [ ] Обложка: 1 объект, 0-4 слова, читается на 150 px, 3 варианта в Test & Compare
  [ ] 0:00-0:05 подтверждение клика, без заставки (в речевом формате - голос с 1-й секунды)
  [ ] 0:05-0:30 ставки ("в конце - самое безумное"), 0:30-1:00 первый результат
  [ ] Блоки 3-7 мин: у каждого свой хук и payoff; таблица блоков заполнена
  [ ] Прогрессия темпа: 0-3 мин плотно (10-20 с), 3-7 шире (25-40 с), после 8 -
      спокойствие + всплески
  [ ] Re-hook каждые 60-90 с; 2-й по силе момент на 40-60%
  [ ] Payoff в конце + переход + end screen 5-20 с; из ролика - 3-6 Shorts
 Промпт:
  "Тема: <...>. Длина: <N> мин. Формат: <эссе/пересказ/топ/доки>.
  1) Сформулируй core question и 4-элементную упаковку: название (65-70 симв., с числом),
     текст обложки (0-4 слова), хук 0-5 с (кадр+фраза+текст), интро 0:05-0:30 (ставки).
  2) Разбей ролик на блоки 3-7 мин: таблица "блок | мин | хук блока | контент | payoff |
     re-hook на следующий".
  3) Для каждого блока: темп по прогрессии (р.5), где B-roll, где число на экране.
  4) Финал: payoff + переход + end screen. Планировка 3 Shorts-тизеров (файл 11, р.8).
  5] Без длинных тире, без эмодзи в кадре. Факты - из 2 источников (файл 19)."
