# `stack`: сборка шортса из кусков

`python tools/shorts.py stack spec.json [--out FILE]` собирает 1080x1920, 25 кадров/с, H.264 + AAC, звук нормализуется (-14 LUFS).

```json
{
  "out": "01-interview.mp4",
  "main": {"pieces": [{"src": "sources/a.mp4", "start": 0.8, "end": 8.2}], "y": 560, "h": 1360, "zoom": 1.45},
  "top": {"src": "sources/game.mp4", "start": 2, "h": 560, "zoom": 1.12},
  "captions": {"srt": "01.srt", "y": 1050, "size": 66, "accent": "#FFD84D", "words": 3},
  "hook": {"text": "ОДИН НЕИЗВЕСТНЫЙ…", "y": 400, "start": 0, "end": 2.6},
  "banner": {"brand": "Quattro VPN", "tg": "QuattroVPN_BOT", "theme": "auto", "url": "t.me/QuattroVPN_BOT",
             "qr_url": "https://t.me/...", "start": 3.0, "y": 330, "slides": [{"title": "...", "sub": "..."}]}
}
```
- `main.pieces`: куски по порядку; время относительно файла из `fetch` (не относительно исходного видео). Звук берётся отсюда.
- `main.y/h/zoom`: окно главного видео. `zoom` больше 1 приближает и держит лицо на 36% высоты кадра. Лицо ищет YuNet,
  на смене плана рамка прыгает, между сменами плавно следует. Без лица рамка по центру.
- `top`: верхнее видео без звука, зацикливается; `zoom` отрезает слева сверху (убирает водяной знак канала-источника).
- Фон: размытая копия главного кадра, чёрных пустот нет.
- `captions`: SRT по времени готового ролика; слова подсвечиваются по очереди (длина слова задаёт время), группы по 3 слова.
  Нецензурные слова в субтитрах маскировать звёздочками (реклама и монетизация).
- `hook`: заголовок в первые секунды; не ставить на лицо и не пересекать с карточкой по времени.
- `banner`: поля `reference/ad-banner-standard.md`; `start`, `end`, `y`, `x`.

Раскладки, проверенные на практике:
1. Интервью с геймплеем сверху: top h=560, main y=560 h=1360 zoom 1.45, карточка y=330 на стыке, субтитры y=1050.
2. Нарезка без верхней панели: main y=0 h=1920, хук y=380, субтитры y=800, карточка y=900 (нижний край 1220 выше интерфейса).

Все безопасные зоны Shorts: сверху 288, снизу 672, справа 192 px. Субтитры и карточка не ниже y=1248.
