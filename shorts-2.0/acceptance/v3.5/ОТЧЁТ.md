# SHORTS 1.7.0 / traffic v3.5: доработка до боевого запуска

Ничего не публиковалось, платные API не вызывались, реклама не запускалась.
Скилл проверяет структуру и самоотчёт; это не гарантия продаж и не разрешение на запуск.

## Что изменено (по приоритетам)
**P0 (запуск без контроля)**
- launch требует reviewer-человека (не автор), 2+ variants, disclosure, свежие доказательства (30 дней).
- Бюджетный лимитер платных API (SHORTS_ALLOW_PAID=1 + SHORTS_PAID_BUDGET>0, fail-closed, paid-ledger.json).
- release-check блокирует нераскрытую рекламу (промокод, партнёрская, #ad и т.п) без campaign.json.
- Блок launch для ссылки в описании/комментарии YouTube Shorts без кликабельного места.
**P1**
- ad-render (баннеры 9x16/1x1/4x5/16x9 + отчёт пересечений/контраста), ad-seal, ad-links, ad-metrics.
- Линтер рекламных текстов (эвристика), метки площадок как предупреждения.
- plan lint `banner_fields` (поля баннера внутри animation молча давали «VPN в Telegram»).
**P2**
- Учебные примеры: static-training пересобран, новый video-training (13,17 с).
- Перепроверка источников 2026-10-20, шаблоны, evals (+7 кейсов), миграция, changelog.

## Не подтверждено / ограничения
- ad-check проверяет структуру и самоотчёт; ничего не проверяет во внешнем мире.
- Линтер текстов эвристический: пропуски и ложные срабатывания возможны.
- Реальных офферов, метрик и доходов нет: пример metrics.example.json воспроизводит арифметику из PDF.
- Бюджет платных API: оценка, не биллинг провайдера.
- ad-render считает макет; смысл, права, реальный UI и вид на телефоне не проверяет.
- Видео-пример синтетический: звук не слушал человек, просмотр не на телефоне и не в интерфейсе площадки.
- Источники прочитаны 2026-10-20, часть через выдержки поиска; страницы Admitad датированы 2022.
  safe_zones.json, AffTrends и Telegram Ads не перепроверялись. YouTube 13778635 не загрузился, не использован.
- Правила площадок меняются: перед запуском перепроверить в интерфейсе.

## Что требует человека
Реальный оффер и допуск источника, права на материалы, назначение reviewer, текст раскрытия,
просмотр на телефоне с UI площадки, согласование публикации и бюджета.
