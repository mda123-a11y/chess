## Правила (скрипт проверяет)
- 5-7 названий, громкость 1 (капс, эмодзи, цифра, крупное обещание) ... 5 (поисковая фраза, без капса и эмодзи).
- До 100 знаков вместе с хэштегами, эмодзи максимум одно, капс только в вариантах 1-2, 3-6 хэштегов, `#shorts` для Shorts.
- Все честные: обещают то, что есть в ролике. Ключевое в начале. Для каждого пометка: поиск или интрига, и почему.
- Описание (ОДНО): до 3 хэштегов (покажутся над названием) / 1-2 предложения / один призыв / ссылки пользователя /
  пустая строка / нижние хэштеги. Всего около 15 уникальных хэштегов, больше 60 = YouTube игнорирует все.
- Ссылки только из настроек и плана. Нет ссылок = их нет в описании (скрипт предупредит).
- Закреп: 3 строки (польза, ссылка, вопрос). TikTok: подпись + до 5 хэштегов.
- Нет длинных тире. Язык = язык ролика.
- Рекомендуй один вариант одной строкой. Для ленты Shorts обычно интрига (2-3), для поиска и канала спокойный (4-5).
- Запомни выбор пользователя (`remember_choice("chosen_title", ...)`): следующие названия подстраивай под него.

## Упаковка по v3.1
- Название, обложка и хук раскрывают одно core question; первые 0-5 с подтверждают обещание.
- Рабочая длина текста названия без хэштегов: длинные 65-70 символов, Shorts около 49.
  Это ориентир, проверяется на ваших цифрах (subsub, англоязычная выборка, просмотры/подписчики,
  НЕ CTR). Это рекомендация, а не причина отклонить честное название; предел 100 с тегами остаётся.
- Число обещанных пунктов не больше числа реально показанных. Агент сверяет с готовым роликом,
  код не умеет достоверно считать смысловые пункты. Год, модель и длительность - не число пунктов.
- Название-вопрос - предупреждение: по этой выборке слабее утверждения с интригой, не запрет.
- CTA выбирай по цели бренда: лайк коротко на пике в середине; подписка - обещанием следующего
  выпуска. Не обещай несуществующее «полное видео». Заполни cta сам, не полагайся на запасную фразу.
- После meta и cover собери `package DIR`: `ПАКЕТ.txt` для человека, JSON остаётся внутренним.

## Эдиты из фильмов (совместимость с правилами 1.2-1.3)
- Название = цитата героя или эмоция ("Город - злая сила"), имя героя/фильма в начале для поиска ("Данила Багров").
- Подпись: 1 строка + 3-5 хэштегов (#эдит #edit #брат #данилабагров #shorts), не 15.
- Ссылка в Shorts не кликается: в кадре ник 2 раза (плашка `link`), в описании полная ссылка, в закрепе тоже.
  В YouTube Studio поставь "Связанное видео" (Related video) на длинное видео/канал, если есть.
- Звук: если пользователь грузит через приложение, можно заменить трек на трендовый из фонотеки (окно тренда 1-3 дня).
