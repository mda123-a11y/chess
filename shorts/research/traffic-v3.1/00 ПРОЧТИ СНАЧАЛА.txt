4. ВОРОНКА "ЗАМЕТИЛ -> КЛИКНУЛ -> ДОСМОТРЕЛ -> ЛАЙК -> ПОДПИСАЛСЯ" (v3.1)
====================================================================
 У каждого шага своя метрика и свой порог диагностики. "100% на каждом шаге" невозможно
 физически; цель - чинить шаг за шагом по метрикам (критика v3, 24, р.2.2).
  ШАГ ВОРОНКИ | ЧТО РЕШАЕТ          | МЕТРИКА                | ПЛОХО, ЕСЛИ
  ------------|--------------------|------------------------|---------------------------
  1. Заметил   | обложка + название | показы, CTR           | CTR стабильно < 3% (06)
  2. Кликнул   | обложка + название | CTR против среднего   | ниже среднего канала в 24-48 ч
     (длинное) |                    | канала [Д 2026]        |
  3. Остался   | хук 0-2 с          | viewed vs swiped      | < 60% (10, р.4)
     (Shorts)  |                    | (Shorts)              |
  4. Досмотрел | сценарий + монтаж  | средний % просмотра,  | обвал в 1-3 с = хук; спуск
              | + payoff           | кривая                 | = нет петель; ступенька = вода
  5. Лайкнул   | эмоциональный пик  | лайки/просмотры       | нет пика = нет золота (26, р.4)
  6. Подписался| серия + профиль    | подписки с ролика     | обещания следующего нет (11)
 Правила воронки:
  - В режиме ГИПОТЕЗЫ чинить один измеренный шаг (21, р.6). В ПЕРЕСБОРКЕ
    слабого видео можно менять всё сразу (26, р.14).
  - Если CTA уместен: лайк можно попросить на пике; подписка - упаковкой "будет ещё"
    (серия, профиль), не просьбой [Д 2025 JRIM, ограниченно: одна англоязычная выборка;
    файл 11, р.3].
  - Shorts-лента не видит обложку: там шаги 1-2 заменяет кадр 0 (10, р.2; 06, р.2).

5. ЗОЛОТЫЕ ПРАВИЛА (если запомнить только это)
====================================================================
  1. Для ленты первые секунды особенно важны; для речи голос сразу часто полезен.
     Безголосый жанр подтверждает ценность изображением, не обязательным голосом. [О/Г]
  2. Для речевого короткого формата хук может объединять кадр, голос и текст; в первые 5 с - подтверждение обещания
     обложки (упаковка = система: название + обложка + хук + интро). [О 2026]
  3. Причина смотреть - вопрос, полезное объяснение, эмоция или наблюдение процесса.
     Ранний ответ допустим в уроке/разборе; в истории развязка может быть позже. [О/Г]
  4. Темп по формату (16, раздел 1): эдит 0.3-1.5 с, факты 1.5-3 с, монолог 3-6 с, длинное
     - прогрессия 10-20 / 25-40 / всплески (28, раздел 5). Пауза-акцент 1-3 с - приём;
     провис без смены и без смысла - ошибка. [О/Г]
  5. Звук под эмоцию, дроп в ключевой момент, голос всегда громче музыки. [О]
  6. Важное в центре (>= 55%) и вне интерфейса (safe-зоны Shorts 288 сверху / 672 снизу /
     192 справа; TikTok 240 / 660 / 300 справа; Reels 269 / 672). Сверять скриншотом
     раз в месяц (25, р.10.4). [О]
  7. Финал завершает мысль. Петля для повтора, мост для продолжения - по задаче,
     не обязательны для урока, интервью, длинного или законченной истории. [О/Г]
  8. Упаковка (название + обложка) придумывается ДО монтажа и не врёт. [О; обман - против П]
  9. 1 главный триггер + 1-2 поддерживающих, не больше 3. [Г]
 10. Сравнивай со своей медианой того же типа. Одна правка только при проверке
     гипотезы; пересборка допускает несколько согласованных изменений. [Г/М]
 11. Чужой материал - только со слоем автора >= 2 (или 1 сильный, файл 25): шаблон поверх
     чужого площадки показывают хуже. [П/Г]
 12. Факты и цифры правдивые, из 2 источников (19); "совпадение", а не "предсказали".
 13. ИЗ СЫРЬЯ - ЧЕРЕЗ ВАУ-ТРАНСФОРМЕР (26): диагностика -> золото -> концепция -> репак ->
     перемонтаж. Эффекты не создают вау, вау = обещание x выполнение x плотность. [v3.1]

7. ГЛОССАРИЙ
====================================================================
 Хук            - первые 1-2 с, которые останавливают пролистывание.
 Подтверждение клика - первые 5 с: показать то, что обещала упаковка. [v3.1]
 Core question  - одно напряжение ролика (тайна, страх, конфликт, трансформация), из него
                  собираются название, обложка, хук и интро. [v3.1]
 Payoff         - выполнение обещания хука (ответ, кульминация, дроп).
 Открытая петля - вопрос/обещание, ответ на который будет позже.
 Петля (loop)   - конец, плавно переходящий в начало (повтор просмотра).
 Re-hook        - новая зацепка посреди ролика ("и теперь самое странное").
 Дроп           - момент, когда трек "взрывается" (бас, бит), обычно главная точка монтажа.
 Velocity       - монтаж с кривой скорости (быстро-медленно-быстро) по битам.
 Look           - цветовая обработка (film, cold, punchy, bw).
 Safe-зона      - часть кадра, не закрытая интерфейсом площадки.
 CTR            - клики / показы (обложка + название, длинные видео).
 Viewed/swiped  - досмотрели начало / пролистали (Shorts, оценка хука).
 AVD, % просм.  - средняя длительность и процент просмотра.
 CTA            - призыв к действию (подписка, лайк, комментарий, переход).
 Related video  - связанное видео под Shorts (мост на длинный ролик).
 End screen     - конечная заставка длинного видео (5-20 с).
 Триггер        - психологическая кнопка (деньги, тайна, страх...), файл 12.
 Плашка         - прямоугольник с текстом-темой ("ЦЕНА ПРИЗНАНИЯ").
 Слой автора    - свой вклад поверх чужого: голос, тезис, свой материал, сравнение (15, раздел 2).
 Золото         - сильный момент сырья: эмоция, факт, конфликт, поворот, аномалия (26, р.4). [v3.1]
 Формат-победитель ниши - формат, который в нише системно выше медианы (27, р.4). [v3.1]
 Выброс         - ролик, набравший в разы больше медианы своего канала (21, раздел 4).
 Медиана канала - середина ряда результатов последних 10-20 роликов того же типа.
 Смена подсчёта - 31.03.2025 подтверждена для Shorts. Дата 24.08.2026 для всех
                  форматов не подтверждена проверенными первичными справками [Г].

 Пороги и приоритеты вместо равных весов (критика v3, 24, P1.6).
 БЛОК P0 (провал любого = НЕ ПУБЛИКОВАТЬ, 0 = нет, 2 = да):
  1. Стоп-кадр: кадр 0 остановит палец даже без звука?

  3. Обещание: для ленты быстро ясно, что получим; хук подтверждает упаковку?
     Открытый вопрос необязателен в уроке/объяснении с ранним ответом [Г].
  4. Честность: факты проверены, упаковка не врёт?
 БЛОК P1 (ядро качества, 0-2 за пункт):
  5. Новое: зритель увидит то, чего нет в топ-10 роликов по теме (19, раздел 4)?
  6. Payoff: выполнен по формату (09, раздел 2.1); после раннего ответа есть
     полезное развитие либо мысль завершена? [Г]
  7. Ремесло: темп, звук и текст по формату (16, 05, 04), нет провисов, QA пройден?
  8. Эмоция: одна понятная эмоция, звук и look ей соответствуют?
 БЛОК P2 (усилители, 0-2 за пункт):
  9. Пересылка: есть момент, которым хочется поделиться?
 10. Слой автора: >= 2 пунктов (или 1 сильный, 25, правки к 15), если материал чужой.
 Итого P1+P2 = 6 пунктов, максимум 12 баллов (4 x 2 + 2 x 2).
 Итог: P0 без провалов + P1/P2 >= 9 из 12 - публиковать; P1/P2 6-8 - исправить самое
 слабое и перепроверить; P1/P2 < 6 - вернуть на концепцию (26, шаг 3), не полировать.

 роликов проверить связь балла с результатом (21) и сдвинуть порог.
