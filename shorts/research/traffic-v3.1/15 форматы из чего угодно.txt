1. КАК ПОЛЬЗОВАТЬСЯ МАТРИЦЕЙ
====================================================================
 Шаг 1. Посмотри, ЧТО есть: фильм, ролик YouTube, статья, пост Reddit, таблица цифр, сайт,
        картинки, голос автора, ничего (только тема).
 Шаг 2. Найди в разделах 3-8 форматы для этого материала (поле "Из чего").
 Шаг 3. Выбери по цели: охват (лента), поиск (ищут словами), перелив (ТГК, длинное, файл 18).
 Шаг 4. Возьми адаптер скилла из поля "Скилл":
        film (сцены фильма, реплики film-lines), video (клип из ролика YouTube по громкости,
        речи, heatmap), site / html (страница или своя вёрстка), text (кинетическая типографика на
        фоне), images (слайды с движением). Раскладка layout.mode: three / top_center /
        center_bottom / center_only.
 Шаг 5. Проверь риск (поле "Риск") и чем ты его закрываешь (раздел 2).
 Формат описан так:
   Из чего | Структура | Раскладка | Звук | Длина | Пример | Скилл | Риск

2. ГЛАВНОЕ ПРАВИЛО ОРИГИНАЛЬНОСТИ
====================================================================
 Политика YouTube о переиспользованном контенте (support.google.com/youtube/answer/1311392 и FAQ
 сообщества 271248162) отключает монетизацию у каналов, где чужое видео выложено "без
 существенных изменений": компиляции без комментария, нарезки чужих клипов, геймплей без
 нарратива, слайд-шоу из чужих картинок без смысла. Разрешено, если ты ДОБАВИЛ ценность:
  - свой комментарий или голос, анализ, ответ на вопрос;
  - монтаж с новым смыслом (сравнение, подборка по идее, история);
  - текст, которого нет в исходнике (факты, разбор, перевод);
  - собственную структуру (топ, до/после, вопрос-ответ).
 Хронология (подробно - файл 22):
  2024-04-30 Instagram: оригиналы вместо репостов в рекомендациях.
  2025-07-15 YouTube YPP: "inauthentic content" (массовое, повторяющееся).
  2025-09-13 TikTok: неоригинальное без творческих правок - вне For You.
  2026-04-30 Instagram: то же для фото и каруселей.
  2026-10-01 YouTube, "Prioritizing original content on Shorts": каналы-агрегаторы и перезаливы
             без существенных изменений получают меньше показов в Shorts.
 Что YouTube называет ценностью (01.10.2026, близко к тексту): оригинальный комментарий,
 уникальный монтаж, сторителлинг - "rather than minor technical edits or template-based
 changes" (а не мелкие технические правки или изменения по шаблону). Нарезки своих длинных
 роликов правило не затрагивает. [П]
 Вывод для скилла: shorts - шаблонный конвейер (одни и те же look, velocity, плашки, переходы).
 Шаблонная обработка чужого фильма = "template-based changes". Поэтому в каждом ролике с чужим
 материалом нужен СЛОЙ АВТОРА - идея и вклад, которых нет в исходнике. Эффекты скилла его не
 заменяют. [Г, вывод из П]
 Правило для агента (v2): в каждом ролике с чужим материалом - слой автора минимум из ДВУХ
 пунктов, один из них - п.1-4 списка ниже. Если их нет - ролик не делать. Почему две, а не одна:
 YouTube (01.10.2026) называет ценностью оригинальный комментарий, уникальный монтаж и
 сторителлинг; Instagram (30.04.2026) не считает оригинальностью рамку, водяной знак и субтитры
 (файл 22). Находки для слоя автора - файл 19.
 Исключение [v3.1, смягчение порога - жёсткий порог без калибровки запрещает годные ролики,
 критика v3 р.4]: достаточно 1 СИЛЬНОГО пункта из п.1-4 (свой голос + разбор, свой тезис, свой
 материал, сравнение) плюс сформулированной одной фразой ценности - если фраза честно отвечает
 на проверку ниже "что останется, если убрать чужой материал". Порог - [Г], калибровать по [М]:
 если ролики с 1 сильным пунктом не уступают роликам с 2 - правило ослабить в журнале (файл 21).
 Слой автора - что считается (нужно >= 2 пунктов, один из п.1-4):
  1. Свой голос: комментарий, разбор, рассказ, мнение (голос пользователя или его текст
     озвучкой).
  2. Свой тезис или угол, которого нет в исходнике: "что герой слушает", "сцены без слов",
     "1 и 2 часть: один ли это герой".
  3. Свой материал рядом с чужим: съёмка мест, свои кадры, свои графики, геймплей с нарративом.
  4. Сравнение или монтаж из нескольких источников с новым смыслом (до/после, параллели,
     хронология), а не одна сцена подряд.
  5. Свой текст в кадре, который несёт мысль (тезис, факт с источником), а не повтор реплик.
  6. Звуковой дизайн под идею: свои SFX, тишина, сведение голоса (не просто трек поверх).
  7. Интерактив: вопрос, выбор, квиз, на который ролик отвечает.
 НЕ считается (часть списка прямо называют Instagram и YouTube):
  - рамка, фон, зеркало, зум, look/фильтр, ускорение, кадрирование 9:16;
  - свой водяной знак, ник, логотип;
  - субтитры с репликами фильма;
  - одинаковые во всех роликах переходы, эффекты, шаблон плашек.
 Проверка за 10 секунд: "Если убрать чужой материал, останется ли что-то моё, ради чего стоит
 смотреть?" Нет - слой автора не набран, ролик не публикуем. [Г]

====================================================================
3. ФОРМАТЫ ИЗ ФИЛЬМОВ И СЕРИАЛОВ
====================================================================
 Для всех форматов раздела: слой автора >= 2 (раздел 2). "Риск" ниже - про охват и reused.

 1) Эдит героя (файл 01)
    Из чего: 15-40 сцен героя + трек. Структура: хук-кадр, build-up, дроп, velocity, петля.
    Раскладка: center_only. Звук: трек с дропом. Длина: 7-20 с. Скилл: edit --line / --classic.
    Риск: охват неоригинального; монтаж по битам - не слой автора (раздел 2).

 2) Монолог с плашкой-темой (kinobust "ЦЕНА ПРИЗНАНИЯ")
    Из чего: одна сцена 20-60 с с поворотом. Структура: плашка-тема -> монолог -> фраза-удар.
    Раскладка: top_center / полоса (файл 14 раздел 2). Звук: оригинал + тихий эмбиент.
    Длина: 30-60 с. Скилл: film. Риск: длинный кусок фильма без своего, добавь плашку-тему и вывод.

 3) "Деталь, которую ты не заметил"
    Из чего: кадр фильма + факт (IMDb trivia, Кинопоиск "знаете ли вы", Fandom).
    Структура: стоп-кадр с кружком/стрелкой (кадр 0) -> "посмотри сюда" -> объяснение -> почему
    важно -> следующая деталь (открытая петля). Раскладка: center_only + плашки-факты (14, раздел 8).
    Звук: голос + тихий напряжённый бит. Длина: 20-45 с. Скилл: film + голос (озвучка TTS или своя).
    Пример: каналы-разборы "Easter eggs", русские "детали в фильмах". Риск: низкий, есть свой текст.

 4) "Сцена: ожидание и реальность / сценарий и фильм"
    Из чего: сцена фильма + книга/сценарий/концепт-арт. Структура: сплит сверху-снизу, слева книга,
    справа фильм; текст "в книге было так". Раскладка: сплит (14, раздел 7) или three.
    Длина: 20-40 с. Риск: низкий.

 5) "Хронология героя за 60 с" (история за минуту)
    Из чего: 10-20 сцен через все части франшизы. Структура: "как X стал Y" -> 5-7 вех с годами на
    плашке -> итог. Раскладка: center_only + плашка года слева внизу. Звук: голос + трек под эмоцию.
    Длина: 45-60 с. Скилл: film (несколько источников). Риск охвата низкий при своём нарративе.

 6) "Реплика-ответ" (сцена как ответ на вопрос из жизни)
    Из чего: короткая реплика из фильма. Структура: текст сверху "когда начальник говорит ..." ->
    реплика героя. Это мем-формат, 5-12 с, петля. Раскладка: top_center (текст-ситуация в верхней
    плашке). Скилл: film-lines -> edit --line. Пример: сотни мем-шортсов "POV: ..."; поиск реплик
    playphrase.me, getyarn.io (файл 19). Риск: средний, ценность в подписи-ситуации.

====================================================================
4. ФОРМАТЫ ИЗ ТЕКСТА И ИНТЕРНЕТА
====================================================================
 7) История Reddit над фоном (sludge, файл 17)
    Из чего: пост r/AITA, r/tifu, r/nosleep, r/ProRevenge, перевод на русский (свой пересказ!).
    Структура: карточка поста (ник, сабреддит, заголовок) 2-3 с -> озвучка TTS -> субтитры по
    словам -> обрыв на кульминации "часть 2" или развязка. Раскладка: фон-геймплей на весь экран +
    карточка в верхней части (как @amazinglul Jjt1fVYBkmQ, 4.9 млн, 188 тыс. лайков).
    Звук: TTS, тихая музыка. Длина: 30-60 с. Скилл: text/images + свой фоновый файл (файл 14, 9.2).
    Риск: высокий (массовый формат, YouTube понижает однотипные), добавляй свою интонацию, вывод,
    переводи и адаптируй, а не читай дословно.

 8) Фейковая переписка (iMessage / Telegram-чат)
    Из чего: придуманный диалог 10-20 сообщений. Структура: сообщения появляются по одному со звуком
    "пуш", поворот в последних 3 сообщениях. Раскладка: чат по центру, фон движ (файл 17).
    Длина: 20-45 с. Скилл: html (вёрстка чата, сообщения по таймеру). Риск: обязательно пометка
    "постановка", иначе введение в заблуждение.

 9) Квиз с таймером
    Из чего: 5-10 вопросов. Структура: "90% не ответят на 3-й" -> вопрос -> таймер 3 с -> ответ ->
    счёт. Раскладка: вопрос в центре, варианты A/B/C, полоса таймера. Звук: тик-так, "дзынь".
    Длина: 30-60 с. Скилл: html или text. Пример: квиз-каналы "Guess the movie by emoji" (эмодзи
    только в названии, в кадре скилл их не рисует, используй кадры). Риск: низкий. Комментарии
    растут ("я ответил 4/5").

10) "Что бы ты выбрал" (would you rather)
    Из чего: пары вариантов. Структура: сплит лево/право, два варианта, "проголосуй в комментах",
    проценты появляются. Раскладка: сплит v2. Длина: 15-40 с. Скилл: images/html. Риск: низкий.

11) Кинетическая цитата / философия на фоне
    Из чего: текст 20-60 слов (цитата, мысль, стих). Структура: фразы по одной, акцентное слово
    крупно, фон медленный. Раскладка: center_only. Звук: эмбиент/фонк медленный. Длина: 10-30 с.
    Скилл: text (уже умеет кинетику на фоне, *слово* = акцент). Пример: @realforgedman HcskifhM6sI
    (11 тыс., статичный список "Научись уважать себя" + ссылка на ТГ). Риск: средний, однотипность.

12) Список-шпаргалка (5-7 пунктов)
    Из чего: полезный список. Структура: заголовок-обещание -> пункты появляются по одному (1 пункт
    = 2-4 с) -> "сохрани". Это формат ради СОХРАНЕНИЙ и перелива ("полный список в ТГК", файл 18).
    Раскладка: center_only. Длина: 8-30 с. Скилл: text/images. Риск: низкий.

13) "Мем-разбор" / происхождение мема
    Из чего: мем + Know Your Meme. Структура: мем на весь экран -> "откуда он" -> 3 этапа истории
    с годами -> текущее состояние. Длина: 30-60 с. Скилл: images + голос. Риск: картинки чужие,
    смысл свой (история).

5. ФОРМАТЫ ИЗ ЧИСЕЛ, ДАННЫХ И ЭКРАНА
====================================================================
14) "Сколько зарабатывает ..." (запись экрана + калькулятор)
    Из чего: Social Blade, статистика, калькулятор. Структура: вопрос-хук -> экран сайта с
    выделением цифры -> подсчёт -> вывод/неожиданность. Пример: @martinesyoutube tW0pmWtcOv0
    "Сколько можно заработать на Ютуб Шортс выкладывая чужие видео?" 8.1 млн, 425 тыс. лайков,
    говорящая голова + скринкасты Social Blade + Related video на длинное. Раскладка: three (верх
    лицо, центр экран) или полноэкранный скринкаст с punch-in. Скилл: site (скролл и зум по
    странице) + голос. Длина: 30-60 с. Риск: низкий, но цифры проверять (триггер денег, файл 12).

15) Сравнение-гонка (bar chart race / "X против Y")
    Из чего: таблица по годам. Структура: два столбика растут, комментатор текстом. Скилл: html
    (графика по таймеру). Длина: 20-45 с. Риск: низкий, данные указывать источником.

16) "Масштаб" (сравнение размеров)
    Из чего: размеры/цифры объектов. Структура: камера отъезжает, объекты больше и больше.
    Скилл: images/html. Длина: 20-60 с. Риск: низкий.

17) Карта (хронология на карте)
    Из чего: история региона, путь героя. Структура: карта, линия маршрута рисуется, точки с годами.
    Скилл: html (SVG-путь, анимация stroke-dashoffset). Длина: 30-90 с. Риск: низкий.

18) Скринкаст-туториал ("как сделать X за 30 с")
    Из чего: запись экрана своих действий. Структура: результат сначала (кадр 0) -> 3-5 шагов с
    зумом на курсор -> итог -> "файл/пресет в ТГК" (файл 18). Раскладка: center_only, зумы.
    Скилл: video (свой файл) или site. Пример: туториалы CapCut/Premiere (flicker 87cynGnmnGg 123 тыс.,
    letterbox CHLRELKJOEc). Длина: 15-60 с. Риск: низкий, это 100% свой контент.

6. ФОРМАТЫ С ЛИЦОМ И ГОЛОСОМ АВТОРА
====================================================================
19) Говорящая голова + вставки (Starikov, файл 02)
    Структура: тезис -> вставка-доказательство -> плашка-факт -> вывод. Раскладка: three или
    сплит. Длина: 30-60 с. Риск: минимальный.

20) Реакция (сверху стример, снизу видео)
    Из чего: чужое видео + твоя реакция. Пример: @StanleyMOVLive -3Z3ER0rgDE (сверху лицо, снизу
    ролик, огромные слова на линии стыка). Раскладка: сплит h2 (верх лицо, низ видео).
    Риск: СРЕДНИЙ-ВЫСОКИЙ: реакция должна быть содержательной (комментарий, пауза, мнение), а не
    молчаливое лицо. Длина: 20-60 с.

21) "Дуэт/ответ на комментарий"
    Структура: скрин комментария (карточка) -> ответ голосом/текстом. Даёт сигнал "автор отвечает",
    растит комментарии. Скилл: images (карточка) + видео автора. Длина: 15-45 с.

22) Голос за кадром + B-roll ("видео-факт")
    Из чего: сценарий + стоки (Pexels, Pixabay, Videvo, файл 19) или кадры фильма.
    Структура: хук-факт -> 3-5 подтверждений, B-roll меняется каждые 2-3 с -> вывод.
    Скилл: images/video + TTS. Длина: 30-60 с. Риск: AI-озвучка однотипна, пиши свой текст,
    меняй голос, не делай "фабрику" одинаковых роликов.

====================================================================
7. ФОРМАТЫ "ФОН + СМЫСЛ" (СВЯЗКА С ФАЙЛОМ 17)
====================================================================
23) Контент сверху + геймплей снизу (sludge split)
    Из чего: любой "скучный" для глаза клип (подкаст, интервью, сцена диалога) + геймплей
    (GTA мега-рампа, Minecraft паркур, Subway Surfers). Структура: верх смысл, низ движение,
    субтитры на линии стыка. Длина: 30-90 с. Подробно: файл 17. Риск: геймплей без смысла =
    reused; сам клип чужой - нужна вырезка с ценностью (лучший момент, перевод, подпись).

24) Подкаст-клип
    Из чего: длинный подкаст/интервью. Структура: самая острая фраза в кадре 0 -> контекст ->
    кульминация. Скилл: video (выбор клипа по речи и heatmap "самое пересматриваемое").
    Раскладка: лицо 9:16 (reframe по лицу) или сплит двух спикеров. Длина: 30-60 с.
    Риск: если не свой подкаст - нужна очевидная ценность (перевод, разбор).

25) ASMR/"удовлетворительное" + факт
    Из чего: видео резки мыла, гидравлического пресса, кинетического песка + голос с фактами.
